= Cluster-Sicherheit und -Performance mit ASA r2 System Insights optimieren
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Zeigen Sie _Insights_ im ONTAP-System-Manager an, um Best Practices und Konfigurationsänderungen zu ermitteln, die Sie auf Ihrem ASA r2-System implementieren können, um Clustersicherheit und -Leistung zu optimieren.

Angenommen, Sie haben Network Time Protocol (NTP)-Server für Ihren Cluster konfiguriert. Ihnen ist jedoch nicht bewusst, dass Sie weniger als die empfohlene Anzahl von NTP-Servern für eine optimale Clusterzeitverwaltung haben. Zur Vermeidung von Problemen, die bei ungenauer Clusterzeit auftreten können, benachrichtigt Insights Sie darüber, dass zu wenige NTP-Server konfiguriert sind, und bietet Optionen, um mehr über das Problem zu erfahren, es zu beheben oder es zu ignorieren.

image:insights.png["Screenshot der Seite „Einblicke in System Manager“"]

.Schritte
. Wählen Sie im System Manager *Insights* aus.
. Besprechen Sie die Empfehlungen.


.Wie es weiter geht
Führen Sie alle erforderlichen Aktionen durch, um Best Practices zu implementieren und die Sicherheit und Performance des Clusters zu optimieren.
