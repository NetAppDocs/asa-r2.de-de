= Starten Sie einen Node auf einem ASA r2-Speichersystem neu
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ein Neustart eines Knotens kann aus Wartungsgründen, zur Fehlerbehebung, für Softwareaktualisierungen oder aus anderen administrativen Gründen erforderlich sein. Wenn ein Knoten neu gestartet wird, führt der HA-Partner automatisch eine Übernahme durch. Der Partnerknoten führt dann eine automatische Rückgabe durch, nachdem der neu gestartete Knoten wieder online ist.

.Schritte
. Wählen Sie im System Manager *Cluster > Übersicht* aus.
. Wählen Sie image:icon_kabob.gif["Drei vertikale blaue Punkte"] neben dem Knoten, den Sie neu starten möchten, und wählen Sie dann *Neustart*.
. Geben Sie den Grund für das Neustarten des Knotens ein, und wählen Sie dann *Neustart* aus.
+
Der von Ihnen eingegebene Grund für das Neubooten wird im Systemauditprotokoll aufgezeichnet.



.Was kommt als Nächstes?
Während der Knoten neu gestartet wird, übernimmt sein HA-Partner die Kontrolle, sodass es zu keiner Unterbrechung des Datendienstes kommt. Nach Abschluss des Neustarts führt der HA-Partner eine Rückgabe durch.
