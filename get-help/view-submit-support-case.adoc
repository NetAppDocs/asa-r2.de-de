= Support-Cases für ASA r2-Speichersysteme übermitteln und anzeigen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Wenn ein Problem auftritt, das Unterstützung erfordert, kann ONTAP System Manager verwendet werden, um einen Fall beim technischen Support einzureichen oder abgeschlossene beziehungsweise laufende Fälle anzuzeigen.

Sie müssen link:https://docs.netapp.com/us-en/active-iq/task_login_activeiq.html["Bei Active IQ registriert"^] sein, um Supportfälle für Ihr ASA r2-System einzusehen.

.Schritte
. Um einen Supportfall einzureichen, im System Manager *Cluster > Support* auswählen und dann *Zu NetApp Support* wählen.
. Ein zuvor eingereichter Fall kann im System Manager unter *Cluster > Support* und anschließend *Meine Fälle anzeigen* angezeigt werden.
