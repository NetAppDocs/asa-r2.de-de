= Ändern der Snapshot-Reserve auf einem ASA r2-Speichersystem
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die Snapshot-Reserve ist der Speicherplatz, der speziell für Snapshots reserviert ist.  Standardmäßig ist die Snapshot-Reserve auf 0 % eingestellt.  Ab ONTAP 9.18.1 können Sie die Standard-Snapshot-Reservierung der Speichereinheit ändern und die automatische Snapshot-Löschung aktivieren.  Die automatische Löschung von Snapshots ist standardmäßig deaktiviert.  Wenn ein Snapshot-Reservewert festgelegt und die automatische Snapshot-Löschung aktiviert ist, werden ältere Snapshots automatisch gelöscht, wenn der von den Snapshots belegte Speicherplatz die Snapshot-Reserve überschreitet.  Dadurch wird verhindert, dass Snapshots Speicherplatz belegen, der für Benutzerdaten vorgesehen ist.

link:snapshot-reserve.html["Erfahren Sie mehr über Snapshot-Reservierung auf ASA r2-Speichersystemen."].



[[modify-snapshot-reserve-on-storage-units]]
== Snapshot-Reservierung auf Speichereinheiten ändern

Um unterschiedliche Snapshot-Reservewerte festzulegen, konfigurieren Sie jede Speichereinheit einzeln.  Um für alle Speichereinheiten denselben Wert zu verwenden, ändern Sie die Snapshot-Reserve auf der Speicher-VM.

.Schritte
. Wählen Sie im System Manager *Storage* aus.
. Bewegen Sie den Mauszeiger über den Namen der Speichereinheit, für die Sie die Snapshot-Reserve festlegen möchten.
. Wählenimage:icon_kabob.gif["drei vertikale Punkte"] Wählen Sie anschließend *Bearbeiten*.
. Unter *Snapshot-Reserve %* geben Sie den numerischen Wert für den Prozentsatz des Speicherplatzes der Speichereinheit ein, der für Snapshots reserviert werden soll.
. Vergewissern Sie sich, dass die Option *Ältere Snapshots automatisch löschen* ausgewählt ist.
. Wählen Sie *Speichern*.


.Ergebnis
Die Snapshot-Reserve ist auf den von Ihnen angegebenen Prozentsatz eingestellt.  Wenn der von Snapshots belegte Speicherplatz die Reserve erreicht, werden ältere Snapshots automatisch gelöscht.



[[modify-snapshot-reserve-on-a-storage-vm]]
== Snapshot-Reservierung auf einer Speicher-VM ändern

Um für alle Storage-Einheiten in einer Storage VM dieselbe Snapshot-Reserve festzulegen, wird der gewünschte Prozentsatz auf die Storage VM angewendet. Wenn die Snapshot-Reserve auf die Storage VM angewendet wird, gilt sie für alle neu erstellten Storage-Einheiten innerhalb der Storage VM. Sie gilt nicht für Storage-Einheiten, die vor der Änderung der Einstellung erstellt wurden.

.Schritte
. Im System Manager wählen Sie *Cluster > Storage VMs* und anschließend *Einstellungen*.
. Unter *Richtlinien* erfolgt neben *Snapshots* die Auswahl von image:icon_kabob.gif["drei vertikale Punkte"]; anschließend die von *Standardwert für Snapshot-Reservierung festlegen/bearbeiten*.
. Unter *Snapshot-Reserve %* geben Sie den numerischen Wert für den Prozentsatz des Speicherplatzes der Speichereinheit ein, der für Snapshots reserviert werden soll.
. Vergewissern Sie sich, dass die Option *Ältere Snapshots automatisch löschen* ausgewählt ist.
. Wählen Sie *Speichern*.


.Ergebnis
Die Snapshot-Reserve für neu erstellte Speichereinheiten ist auf den von Ihnen angegebenen Prozentsatz festgelegt.  Wenn der von Snapshots in diesen Speichereinheiten belegte Speicherplatz die Reserve erreicht, werden ältere Snapshots automatisch gelöscht.
