= AIX-Hosts für SnapMirror active sync auf ASA r2 Systemen vorbereiten
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ab ONTAP 9.19.1 unterstützt SnapMirror active sync Transparent Application Failover für AIX-Hosts in symmetrischen Aktiv/Aktiv-Konfigurationen. SnapMirror active sync ermöglicht den weiteren Betrieb von Business-Services auch bei einem vollständigen Standortausfall, indem Applikationen per transparentem Failover auf eine sekundäre Kopie umgeschaltet werden.

Bevor Sie SnapMirror active sync für Ihre AIX-Hosts mit ONTAP 9.19.1 oder höher aktivieren können, muss der Host-Zugriffsmodus auf lokal eingestellt sein. Die Auswahl des Zugriffsmodus ist für andere Hosttypen nicht erforderlich. Weitere Informationen zu link:https://docs.netapp.com/us-en/ontap/snapmirror-active-sync/interoperability-reference.html["Interoperabilität für SnapMirror active sync"^].

.Bevor Sie beginnen
Sie müssen ONTAP 9.19.1 oder höher ausführen. Wenn Sie ONTAP 9.18.1 oder älter ausführen, ist für die AIX-Host-Unterstützung für SnapMirror active sync ein Feature Policy Variance Request (FPVR) erforderlich.

.Schritte
. Wählen Sie im System Manager *Storage* aus.
. Bewegen Sie den Mauszeiger über den Namen der AIX-Speichereinheit, die Sie für den SnapMirror Aktiv-Sync-Schutz vorbereiten möchten.
. Wählen Sie image:icon_kabob.gif["Menüauswahlsymbol"] und anschließend *Bearbeiten*.
. Wählen Sie unter *Hostinformationen* für den *Zugriffsmodus* die Option *lokal* und anschließend *Bearbeiten*.


.Was kommt als Nächstes?
Die Speichereinheit für den AIX-Host ist bereit für SnapMirror Active Sync-Schutz.
