= Speichereinheiten auf Ihrem ASA r2 System löschen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Eine Speichereinheit kann gelöscht werden, wenn die darin enthaltenen Daten nicht mehr aufbewahrt werden müssen. Das Löschen von nicht mehr benötigten Speichereinheiten kann dazu beitragen, Speicherplatz für andere Hostanwendungen freizugeben.

.Bevor Sie beginnen
Wenn sich die zu löschende Speichereinheit in einer Konsistenzgruppe befindet, die in einer Replikationsbeziehung steht, muss link:../data-protection/manage-consistency-groups-add-remove-storage-units.html#remove-a-storage-unit-from-a-consistency-group["Entfernen Sie die Speichereinheit aus der Konsistenzgruppe"] dies vor dem Löschen erfolgen.

.Schritte
. Wählen Sie im System Manager *Storage* aus.
. Bewegen Sie den Mauszeiger über den Namen der zu löschenden Speichereinheit.
. Wählen Sie image:icon_kabob.gif["Drei vertikale blaue Punkte"]; und dann *Löschen*.
. Bestätigen Sie, dass der Löschvorgang nicht rückgängig gemacht werden kann.
. Wählen Sie *Löschen*.


.Was kommt als Nächstes?
Sie können den Speicherplatz, link:modify-storage-units.html["Vergrößern Sie die Größe"]der von der gelöschten Speichereinheit zu  den Speichereinheiten freigegeben wird, die zusätzliche Kapazität benötigen, verwenden.
